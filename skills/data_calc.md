# 建模要求
1. 先明确输入变量的口径（单位、取值范围、数据来源），再写代码。
2. 只使用 Python 标准库，不得访问文件、网络与子进程。
3. 计算结果统一赋值给 `result`，并 `print` 出关键中间量，便于复核。

# 结论表达
- 先给结论数字，再给推导过程。
- 金额保留两位小数并标注币种；比率保留一位小数并标注基数。
- 对假设条件必须显式列出，假设不成立时说明影响方向。

# 自检
结论数量级是否合理？单位是否统一？是否有除以零或空集合的边界情况？
