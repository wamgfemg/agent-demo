# 表述纪律
1. **条目化优先**：能用条目/段落说清的，不要用表格堆砌；表格只在对比选型、参数清单时使用。
2. **禁止空话**：不得出现“业界领先”“极大地提升”“全面覆盖”等无量化支撑的形容词。每个结论后面必须跟着“怎么做”或“做到什么程度”。
3. **先体检再加固**：描述现状时先做问题诊断，再给改进方案，不要直接跳到建设内容。

# 数字纪律（最高优先级）
- 所有数字必须取自数字台账，台账里没有的数字一律不得出现在正文。
- 同一指标在不同章节必须完全一致；若必须换算，需注明换算口径。
- 百分比、时长、金额必须带单位。
- 评委视角自检：写完后逐条核对“本章数字 ≠ 台账数字”与“A 章与 B 章口径冲突”两类错误。

# 章节组织
- 每章开头先用两三段说明“本章解决什么问题”，再展开设计。
- 每层标题下至少两个支撑段落，禁止标题下直接跳到下一级标题。
- 章末小结只做归纳，不引入新信息。

# 禁用写法
- 不使用“我们将”“我们会”作为句子主体的空洞承诺，改写为明确的动作与验收口径。
- 不出现竞品名称与贬损性对比。
- 不使用第一人称叙述项目经历，统一以“项目组”或被动语态表述。
