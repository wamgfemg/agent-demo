# 页面结构
- 首页：项目名称 + 副标题，不放大段正文。
- 内容页标准结构：一句结论式标题 + 3 至 5 条要点 + 讲稿备注。
- 每页只讲一件事，禁止把两个主题塞进同一页。

# 要点写法
- 要点是"结论短句"，不是段落：每条控制在 18 字以内。
- 采用"问题 → 方案 → 成效"或"现状 → 差距 → 举措"的结构化表达。
- 需要数据时用具体数值，不写"大幅提升"。

# 讲稿备注
每页必须写备注，包含：本页要传递的核心信息、与哪个评分点/业务痛点对应、现场可展开的补充案例。

# 视觉风格
科技绿主色（#16A34A），标题绿色加粗，正文深色；一页一图，禁止图文混排堆砌；所有元素必须是可编辑文本框，不得使用图片粘贴正文。
