# 报告结构
固定四段，顺序不可调换：进度 → 风险 → 待办 → 下周计划。

- **进度**：只写已完成与在办事项。已完成项标注完成时间或对应里程碑，不写"正在推进中"这类无信息量的表述。
- **风险**：每条必须包含四项——等级（高 / 中 / 低）、现象描述、影响面（影响哪个交付物或哪个节点）、建议责任人。
- **待办**：写成可验收的动作，含责任人与截止时间。禁止出现"继续跟进""保持关注""加强沟通"这类无法验收的表述。
- **下周计划**：与待办项一一对应，不引入输入资料之外的新事项。

# 表述要求
- 结论先行：每段第一句给结论，后面才是依据。
- 只使用输入资料里出现过的事实与数字；资料没写的不要补，缺什么就写"资料未提供"。
- 不确定的信息标注「待确认」，不要写成既定事实。
- 不使用"大幅""显著""有力"这类没有量化支撑的形容词。

# 自检清单
- [ ] 四段齐全，顺序为 进度 → 风险 → 待办 → 下周计划
- [ ] 每条风险都带等级与建议责任人
- [ ] 每条待办都带责任人与截止时间，且可验收
- [ ] 下周计划与待办项一一对应，没有凭空新增
- [ ] 报告里的数字与输入资料一致，没有自行补写
